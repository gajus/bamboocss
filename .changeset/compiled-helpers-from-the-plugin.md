Import the helpers compiled code calls, `cvaMap` and `splitProps`, from `virtual:bamboo/compiled`, a module the Vite
plugin serves from its own release, instead of from a `styled-system`. They came from a `styled-system/css` the module
or its recipe's module imported, which for a recipe of a workspace design system could be that package's own
`styled-system`, generated by another release. The tables `cvaMap` reads changed format three times in 1.64.8, and the
`cvaMap` of 1.64.7 reads a table 1.64.8 writes for a wide recipe as selecting nothing: the element lost its recipe's
classes, with no error. A compiled call and the helper it reaches now always come from the same release.

The generated `styled-system/css` and `styled-system/css/cx` no longer export `cvaMap` and `splitProps`, which only
compiled code imported.
