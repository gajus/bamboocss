---
title: Using Angular
description: Current support status for Bamboo and Angular.
---

<Callout type="warning">
  Angular's build system does not expose the Vite plugin pipeline Bamboo requires, so Angular is not currently
  supported.
</Callout>

`@bamboocss/postcss`, `bamboo init --postcss`, and a stylesheet generated by `cssgen` do not provide an alternative.
Generated `css()`, recipes, and patterns are compile-time APIs and throw if a Vite build did not replace their calls.

Use a framework with a configurable Vite build and follow [Using Vite](/docs/installation/vite).
