---
title: Using PostCSS
description: Bamboo is a Vite integration. The PostCSS package is not a styling pipeline.
---

Bamboo styles a project only through [`@bamboocss/vite`](/docs/installation/vite). Import `virtual:bamboo.css` from a
JavaScript or TypeScript module and list `bamboocss()` in the Vite config. Vue, Svelte and Astro compile after the
framework plugin; there is no extraction-only PostCSS fallback.

`@bamboocss/postcss` remains as a named export so an old `postcss.config.cjs` fails loudly instead of emitting a second
stylesheet. `bamboo init --postcss` throws the same error. Remove the plugin from PostCSS and follow the Vite guide.

PostCSS is still fine for autoprefixing or other CSS transforms that are not Bamboo.
