---
title: Using Redwood
description: Use Bamboo in Redwood projects that expose a Vite plugin pipeline.
---

Bamboo requires direct access to the application's Vite plugin list. Redwood distributions and versions use different
web build pipelines, so first confirm that your web application has a `vite.config.ts` you control.

If it does, follow [Using Vite](/docs/installation/vite):

1. install `@bamboocss/dev` and `@bamboocss/vite` in the web workspace;
2. add `bamboocss()` to that Vite configuration;
3. include the web source files in `bamboo.config.ts`; and
4. import `virtual:bamboo.css` once from the web entry module.

<Callout type="warning">
  A Redwood setup that does not expose Vite plugins is not currently supported. `@bamboocss/postcss` and `bamboo init
  --postcss` are not fallbacks: generated style APIs require source compilation and throw when they run.
</Callout>
