---
title: Using Remix
description: Use Bamboo with Vite-based Remix and React Router applications.
---

Current Remix and React Router applications build with Vite. Follow the
[React Router guide](/docs/installation/react-router) to install `@bamboocss/vite`, compile style calls, and import
`virtual:bamboo.css`.

<Callout type="warning">
  Classic Remix projects with `remix.config.js` and no Vite configuration are not supported. Do not use
  `@bamboocss/postcss` or `bamboo init --postcss`; generated style APIs require source compilation and throw when they
  run.
</Callout>
